# S3-Compatible Storage

Use this for AWS S3, R2, Tigris, MinIO, B2, Wasabi, Spaces, Ceph, and NetApp.

## Configure

```bash
trunks storage create --name primary s3://company-trunks
trunks storage ping primary
```

Equivalent structured form:

```bash
trunks storage create --name primary --backend s3 --bucket company-trunks
```

For an S3-compatible endpoint:

```bash
trunks storage create --name primary \
  --backend s3 \
  --bucket company-trunks \
  --endpoint https://example-s3-compatible-endpoint.com \
  --region auto
```

## Credentials

Use provider environment variables, IAM roles, or locally saved credentials.

Common S3-compatible variables:

```bash
export AWS_ACCESS_KEY_ID=...
export AWS_SECRET_ACCESS_KEY=...
export AWS_REGION=us-east-1
export AWS_ENDPOINT_URL=https://example-s3-compatible-endpoint.com
```

Local saved credentials:

```bash
trunks storage create --name primary \
  --backend s3 \
  --bucket company-trunks \
  --access-key "$S3_ACCESS_KEY_ID" \
  --secret-key "$S3_SECRET_ACCESS_KEY" \
  --endpoint "$S3_ENDPOINT_URL" \
  --region "$S3_REGION"
```

Saved credentials stay in local Trunks config. They are not written to the backend.

## Layout

```text
s3://company-trunks/trunks/my-app.trunk/
  objects/
  refs/
  journals/
  locks/
```

## Permissions

The credential needs object read, write, delete, and list permissions for the chosen prefix.
